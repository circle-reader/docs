# Circle 阅读助手 v2.7.0

关键词：知识管理、阅读进度、数学公式。

从 v2.7.0 版本开始，Circle 阅读助手开始着手知识管理的功能开发，接下来我们将会上线客户端（暂定支持移动端和电脑端）。当前版本主要对已有的稍后读的重构，独立稍后读为单独的页面。

看文字太枯燥？[视频介绍在此](https://www.bilibili.com/video/BV1W24y1t7DN/)！！！

## 新增

- 识别算法大升级；支持更多字段的识别和展示，如作者，发布时间等信息。
- 增加文章标签的展示；含有文章标签的页面会在内容底部展示，点击可以跳转到搜索引擎查看当前站点相关的内容。
- 代码样式支持自定义；支持字体大小、行距和颜色设置等。
- 背景图片支持上传前裁切；删除对图片 2m 大小的限制。
- 公式支持；支持部分网站的公式，遇到不知道可以反馈给我。
- 上线阅读进度；支持查看当前阅读的进度，在设置页面还可以设置进度条展示的位置。

## 修改

- 浏览器 icon 调整；线条加深，删除原本禁用状态的灰色，使用黑色替代，解决浏览器自定义主题时看不清的问题。如果你是**设计师**，并且对 Circle 阅读助手的界面有**更好的想法**，可以联系我哈。
- 重构稍后读界面；独立成单独的页面，增加更多的筛选项，布局基础的知识管理功能。
- 合并全屏和退出全屏动作；点击全屏，再次点击即可退出（快捷键和右键菜单同理）。
- 黑白名单支持[主域名](/lists_host)（匹配全站）、[网址](/lists_url)（匹配当前页面）、[minimatch](https://www.npmjs.com/package/minimatch) 和正则表达式(格式为：\[实际的正则表达式\] ；即用 \[\] 包裹表达式，传入 new RegExp 实现)，黑白名单管理界面允许修改页面地址；
- 主图位置修改；主图放入内容上面展示。
- 修改禁用纸张效果时的背景颜色；老版本非背景颜色，而是背景颜色计算出来更深的颜色。

## 修复

- 修复打印时有的页面直接崩溃的问题。
- 修复导出时选择图片内链时失败的问题。
- 修复打印时图片被拦腰截断的问题。

## 下线

- 语雀由于上线了会员功能， API 需要付费才可以使用（目前功能基本废了，后期接入其他平台时再处理）。
- 手动选择功能删除时间字段的选择，大部分字段根据内容的位置，会自动计算，无须额外处理。
- 下线工具栏图标的提示：老的逻辑的鼠标放在图标上超 400 毫秒就会展示图标的提示信息，新版本使用浏览器原生功能实现。

本次更新带来了很多功能，除了带来了大量应用之外，还极大的丰富了快捷键、右键菜单和工具栏的选项。新版本带来了“应用市场”，随着“应用市场” 的上线，所有的应用的开启方式都支持三种，分别是快捷键、右键菜单和工具栏的按钮。只要你可以在其中任何一个上面看到，另外两个都支持。以下提到的 “进入”，均可以通过这三种方式中的任一一种开启。

![](https://circlereader.com/themes/circle/assets/img/style.png)

问：设置页面选项太多，如何快速找到我需要修改的选项？

答：设置面板右上角上线了 “在设置内搜索” 功能，直接搜索需要修改的选项即可

问：我的需求只是阅读的辅助功能，可以让扩展简单一点，对我们小白更友好一点吗？

答：新上线的应用市场，允许你直接管理需要的应用；不需要的应用禁用后，不仅不会加载运行，设置面板相关的选项也会跟着消失掉，做到真正的干净。

问：公司和家里的浏览器都安装了，每次配置都要导入导出的好麻烦？

答：“数据同步” 应用解决你的需求，数据保存在云端，再也不怕数据丢失了。注： Circle 非常在意数据的安全性，所有的数据都离线保存在你的设备上，作为开发者也获取不到。上传到云端将会打破这个设定，请知晓！

问：“手动选择” 和 “移除内容块” 用的我好累，每次都要使用一次，可以记下来下次自动运行吗？

答： “规则” 应用帮你搞定，确保 “规则” 已启用之后，再次操作 “手动选择” 和 “移除内容块” 将会记录你的选择到你的设备中，下次同一个网页将会直接使用上次的选择。

问：主题可以跟随系统切换，样式可以一起吗？
