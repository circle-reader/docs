# Circle 阅读助手用户手册

## 简介

Circle 阅读助手是一款免费好用的浏览器扩展程序，可以把网页中的内容提取出来，重新排版整理成更方便阅读的排版界面。采用自研的识别引擎和排版引擎，识别和排版能力更快更出色更强劲。

## 使用

如果一切就绪，浏览器右上侧会出现一个绿色空心圆圈图标（部分浏览器会折叠在一块，请展开查看）。

试着点击一下 ～

如果此时你看到的界面里没有任何广告且排版发生了很大的变化，恭喜你已经掌握了 Circle 阅读助手的使用！再次点击即可退出。

## 原理

**⚠️ Circle 阅读助手是基于算法识别正文的阅读软件，如果网页不含有正文或者噪音过多则会识别失败，绿色圆圈则会变成灰色不可点击的状态。只有识别成功才会变成绿色，才可以通过点击进入阅读模式。所以你会发现同一个网站不同的页面有的可以而有的不行。**

由于是算法识别，对于识别失败的页面，你也可以通过继续点击浏览器右上角 Circle 阅读助手的按钮来触发手动选择模块，辅助 Circle 阅读助手理解正文所在的区域。

## 快捷键

为了提高操作效率，Circle 阅读助手支持快捷键操作。

双击 “a” 键可以快速进入或者退出了 Circle 阅读助手的排版界面。Circle 阅读助手支持的所有快捷键你可以通过按下页面上 ⚙️ 样的图标打开偏好设置页面，在偏好设置页面找到快捷键。

## 定制功能

Circle 阅读助手是模块化开发的，各个功能由不同的模块提供，你可以通过开启相关的模块来实现不同的功能。

通过偏好设置页面右上角的图标进入应用市场，滑动页面浏览提供的模块和功能介绍，开启你需要的功能即可。当对应的模块开启之后，相关的选项才会在偏好设置页面出现。你也可以禁用不需要的功能，进一步简化 Circle 阅读助手的功能。

## 多页解析

当前继续滚动页面到底部会自动加载其他页面的信息拼合到当前页面，这是看小说或者多页新闻用户的福音。如果你不喜欢这个功能，可以按照上面 ”定制功能“ 进入到应用市场，滑动页面找到”多页解析“，关闭其右侧的按钮，此时你就学会了定制 Circle 阅读助手的功能。
