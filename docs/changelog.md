# 🎉 Circle 阅读助手 v3.4.2 焕新登场 🎉

**号外号外！清明节期间升级高级帐户打七折！**

## 🌟 新功能

- 上线[数据备份](/backup.md)，害怕数据丢失？将所有数据备份到云端吧。
- 上线[导出到熊掌记](/export_bear.md)，一键将正文导出到熊掌记。
- 上线[导出到 WordPress](/export_wp.md)，一键将正文导入到您的 WordPress 网站。

## 🚀 新增

- 工具栏新增“平铺展开”选项，新版本把工具栏按钮分组合并展示，开启该选项可以恢复旧版效果。
- 意见反馈面板对于已确认的问题，支持补充更多信息。

## 🛠 修改

- 帐户中心重置密码不再需要老密码，验证邮箱确认是本人操作。
- 帐户中心支持右键菜单，快捷键打开。
- 使用大模型翻译所有的非中文文件，实现彻底国际化，切换语言右键菜单等相关的信息都会切换成对应的语言。
- 悬浮盒子和批注管理默认开启“复制”和“复制为 Markdown” 按钮。
- 更新”应用市场“图标，右键菜单默认启用应用市场。
- 快捷键“偏好设置”默认开启，可以通过按 s 和 t 键打开，也可以自定义键值。
- 版本更新不再强制打开更新日志页面，而是改为弹窗提醒，可以选择是否查看更新日志。
- 安装引导删除“跳过”功能，“完成”按钮修改为“定制功能”，引导用户熟悉和了解“应用市场”。
- 右键菜单去掉“隐藏图片”操作。
- 重构消息中心，快捷键去掉消息中心操作。
- 解析引擎“不解析”修改为“更多字段”，默认仅展示标题和内容，作者，字数统计等默认不启用。
- 移除不常用的功能，进一步优化包体积。

## 🩹 修复

- 修复应用中心报错的问题。
- 修复自动同步失败的问题，默认不进行数据更新时，默认 12 小时从服务器拉取一次数据。
- 修复消息提示框被遮挡问题。
- 修复悬浮盒子在 opera 浏览器下被遮挡问题。
- 修复 Safari 下复制失败的问题。
- 修复选项页面智能识别标题错误问题。
- 修复悬浮盒子启用，滚动复制无法选择文本的问题。
- 修复大声朗读重复读同一个段落两次的问题。
- 修复稍后读页面导出内容失败问题。

**每一次更新，都是为您的阅读体验护航**
