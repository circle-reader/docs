# Circle 阅读助手 v3.4.0

[Circle 阅读助手现已支持 Safari 浏览器啦！](https://circlereader.com/safari-download)

## 新增

- 帐户模块的“我的反馈”可以查看回复信息。
- 反馈模块“提交反馈”页面增加“常见问题” 链接。
- 反馈模块的“热门反馈”可以查看回复信息。

## 修改

- 导出内容片段时默认删除品牌标识。
- “移除品牌标识”增加查看[详情页面](/faq/slogan.html)

## 修复

- 修复接口报错
- 修复登录失败
- 修复批注光标闪烁问题。
- 修复稍后读页面导出数据失败问题。
- 修复进入阅读模式后退出再次进入需要手动选择问题。
