# Circle 阅读助手 `v3.4.5`

## 新增

- 上线全量版 👉🏻 [油猴脚本](https://greasyfork.org/zh-CN/scripts/440132-circle-%E9%98%85%E8%AF%BB%E5%8A%A9%E6%89%8B)。
- 上线 [缩放比例](/zoom.md)，保证任何缩放比例网页进入阅读模式都是同一个固定比例。
- 上线 [兼容模式](/compatible.md)，兼容其他浏览器扩展，如沉浸式翻译。
- 尽管开启“兼容模式”可以使用“沉浸式翻译”，但是译文的高亮样式会丢失，为此我们定制上线 [兼容沉浸式翻译](/immersive.md) 扩展。

## 修改

- 消息中心支持弹窗打开。
- 非 Chrome 内核浏览器自定义字体候选列表放入云端。
- 为帐户注册和重置密码页面添加验证码为空时的多国语言版本。
- 快捷入口（仅非电脑端扩展才显示）和浏览器右上角按钮一样支持多形态。

## 修复

- 修复提交反馈不显示报错的问题。
- 修复进入阅读模式自动进入全屏开启失败问题。
- 修复工具栏手机端按钮偏移问题。
