## 重构

### 切换储存方式

为了提高查询效率，满足大数据储存需求，我们使用的 IndexDB 存储数据，但是部分用户反馈数据和配置会因为版本更新而丢失。为了解决这个问题，最终切换为浏览器扩展自带的储存，以此来解决帐户掉线，配置丢失问题。

### 重构导出为 Word

老版本的 doc 格式不变，对 docx 格式进行了增强，增强之后导出的 Word 文件支持 Microsoft Word 2007+、LibreOffice Writer、Google Docs、WPS Writer 等软件，也支持导入飞书等平台。

### 重构导出为 Epub

老版本使用 epub.press 的接口导出 Epub 文件。新版本支持直接导出 Epub 文件，当浏览器不支持时采用老版本的逻辑兜底。

目前已知火狐浏览器下不支持，相关链接：https://github.com/Stuk/jszip/issues/759

## 修改

- 删除电脑端页面右下角的圆圈，仅手机端和 Pad 端显示；你也可以在应用市场彻底禁用。
- 优化[内容剪藏](/web_clipper.md)，提供剪藏按钮，辅助其他软件一起使用。
- 优化阅读时间显示，老版本阅读时间过长，根据常规阅读用时重新计算。

## 修复

- 修复火狐浏览器下无法编辑的问题。
- 修复 picture 标签导致的离线图片失败，如导出 B 站专栏为离线 HTML 失败问题。
