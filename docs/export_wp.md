## 简介

把经过 Circle 阅读助手排版之后的正文导出到 WordPress 网站。

## 版本要求

仅在 `v3.4.2`+ 版本提供。

## 系统要求

- 需要 WordPress 网站启用 REST API，WordPress 4.4+ 版本自带该功能，老版本可以手动安装。
- 固定链接设置**非**朴素结构， REST API 的需要，如果是默认的朴素结构会导致文章提交失败。
- 网站启用 SSL ，即域名以 https 开头，否则无法配置下面的 “应用程序密码”。

## 启用

偏好设置的应用市场里面找到导出到 WordPress，开启右侧的开关。

## 配置

偏好设置的高级设置里找到导出到 WordPress，当前提供五个选项：网站地址、用户名、应用程序密码、携带图片、名称模版和文件模版。

### 网站地址

WordPress 网站的地址，如 https://circlereader.com。

### 用户名

WordPress 网站上用于保存文章的用户名。

### 应用程序密码

WordPress 网站后台进入保存文章的用户编辑页面。

在页面底部找到“应用程序密码”，在“新的应用程序密码名称” 中输入 “Circle 阅读助手”（其他任何名字都可以）。输入完成点击底部的“新增的应用程序密码” 按钮。稍候会在页面底部显示创建的密码，这个密码就是我们需要的数据。

### 携带图片

开启后，保存正文时，把正文中的图片一起保存到 WordPress 服务器上。

### 名称模版

默认是以当前网页标题作为文件名称导出的，在这里支持自定义。

### 文件模版

默认 Circle 阅读助手是以所见即所得的一个格式导出的。如果想要定制导出的内容可以在这里定制导出内容的模版。

## 使用

启用导出到 WordPress 之后，对应的操作按钮会出现在工具栏、快捷键、右键菜单上。如果发现没开启，需要在偏好设置上面启用下。选择自己偏好的操作按钮点击即可。
