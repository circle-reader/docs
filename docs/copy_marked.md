## 简介

复制经过 Circle 阅读助手排版之后的正文为 Markdown 格式。

## 启用

偏好设置的应用市场里面找到复制为 Markdown，开启右侧的开关。

## 配置

偏好设置的高级设置里找到导出为 HTML，当前提供二个选项：文件模版和文件片段模版。

### 文件模版

默认 Circle 阅读助手是以所见即所得的一个格式导出的。如果想要定制导出的内容可以在这里定制导出内容的模版。

### 文件片段模版

配合[悬浮盒子](/floatbox.md)划选文本时执行导出时，就是文件片段的导出。在这里可以定制导出文件的内容。

## 使用

启用复制为 Markdown 之后，对应的操作按钮会出现在工具栏、快捷键、右键菜单、批注和悬浮盒子上，如果发现没开启，需要在偏好设置上面启用下。选择自己偏好的操作按钮点击即可。
