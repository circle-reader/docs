# 内容剪藏

## 简介

搭配 [Web Clipper](https://clipper.website/) 实现把正文导出到第三方平台。

## 版本要求

仅在 `v3.4.5`+ 版本提供。

## 启用

偏好设置的应用市场里面找到 Web Clipper，开启右侧的开关。

## 使用

启用 [Web Clipper](https://clipper.website/) 之后，当阅读模式可以进入即图标变绿色就可以正常操作 [Web Clipper](https://clipper.website/) 实现导出。

## 原理

当前插件会检测 [Web Clipper](https://clipper.website/) 的点击事件，当你通过 [Web Clipper](https://clipper.website/) 按钮开始剪藏内容时自动把 Circle 阅读助手排版过的正文替换掉原文。所以操作完后记得刷新页面恢复现场哦 😆
